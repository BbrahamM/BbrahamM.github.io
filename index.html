The Challenge: Shipping a dual-language (English/Japanese) fully voiced narrative title on Nintendo Switch under strict memory budgets and certification rules. Synchronous asset loading caused main-thread hitches, and standard file I/O does not comply with Nintendo Switch nn.fs atomic save-data transaction rules during OS sleep or game-exit events.

The Solution: Architected a decoupled C# runtime separated via Assembly Definitions (.asmdef). Engineered deterministic chapter streaming using Addressables and UniTask with explicit handle release on episode transitions. Built a custom Unity Editor validation window to automate CSV/Excel dialogue parsing and Wwise audio GUID binding, alongside a transactional Nintendo Switch save system guarded against mid-write interruptions.

Combat Math Isolated from VFX/UI

The Challenge: Designing a scalable turn-based RPG combat and inventory architecture where designers could iterate on 50+ items, equipment pieces, and skill formulas without creating tight coupling between combat math, Cinemachine cameras, UI presenters, and particle VFX.

The Solution: Isolated combat sequencing (BtlTurnBaseManager), pluggable skill calculations (BtlASkillFormula using the Strategy Pattern), and atomic item reservations (BtlItemPool) behind strict interface and event contracts. Built an automated Python serialization pipeline that converts external balancing spreadsheets directly into runtime Unity JSON schemas.

3. Rendering Optimization & Custom Mesh-Combining Tooling

Fate of Windshift & Windshift

Shipped on PC (Steam) | C#, Unity EditorWindow, Mesh API, Draw Call Batching, Frame Debugger Profiling
-75% Batches
Draw Calls (~4,000 to <1,000)
Locked 60 FPS
Open-World 3D Scene Baseline

The Challenge: Dense 3D open-world environments suffered from severe CPU render-thread bottlenecks caused by thousands of unbatched static props and fragmented multi-material submeshes, pushing draw calls above 4,000 per frame.

The Solution: Authored a custom C# Unity Editor utility using the Mesh.CombineMeshes API to spatially group static geometry, merge shared material submeshes, and preserve lightmap UVs and colliders non-destructively—slashing draw calls under 1,000 batches and locking a steady 60 FPS.
